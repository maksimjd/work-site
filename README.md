Небольшой набор инструментов в одном месте. Сайт написан на чистом HTML/CSS/JS, без фреймворков и сборки — всё в одном файле index.html.

Ссылка на сайт:  https://maksimjd.github.io

⚠️ Сайт находится в активной разработке. Что-то может работать не идеально, какие-то разделы ещё добавляются. Спасибо за понимание.

Что внутри:

💬 Генератор комментариев — если не хочется придумывать комментарий по теме поста или видео, можно сгенерировать готовые варианты через DeepSeek API или Pollinations API.

🎨 Генерация картинок — генерация изображений по текстовому описанию через Pollinations.

🔑 Генератор паролей — случайные сложные пароли для сайтов и сервисов. Длина настраивается, есть индикатор надёжности. Работает сразу, ничего настраивать не нужно.

Как пользоваться:

Генератор паролей — открыл и пользуйся, всё работает без настройки.

Генератор комментариев и генерация картинок — для этих разделов нужно указать API-ключ. Ключ вводится один раз, сохраняется в браузере и дальше подставляется автоматически. Рядом с полем ввода есть ссылка, где ключ получить.

Возможности:

🌗 Тёмная и светлая темы (переключается кнопкой, сохраняется в браузере).

💾 Все настройки сохраняются локально — ключи, история запросов и паролей.

📋 Копирование комментариев одной кнопкой, скачивание в TXT.

📜 История последних паролей и последних запросов картинок.

👥 Счётчик онлайна (работает между вкладками одного браузера).

📱 Адаптивно под телефон.

Статус
Проект молодой, будет развиваться. Разделы и функции добавляются постепенно. Если что-то не работает — возможно, оно ещё в процессе доработки.
